# Dev Island 0.4.0

- Hold the island header without accidentally triggering hover expansion.
- A visible grip identifies the draggable header; moving off the notch preserves the grab point.
- Dragging pauses alert timers and supports Escape to restore the previous position.
- Official signed releases support in-app updates, hourly checks and optional beta builds.
- Existing preferences, sessions and terminal routing are preserved.

The first 0.4 installation is manual; later official releases update through the app.
