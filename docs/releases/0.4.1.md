# Dev Island 0.4.1

- Pinned islands expose a 64×32 pt Move handle below the menu bar in both session and notification panels.
- Drag the handle to detach and move in one gesture, or click to detach into the usable screen area.
- Body dragging preserves the actual grab point when the notch header changes size.
- Escape cancellation stays with the input that owns the gesture; automatic AppKit window movement cannot compete.
- Compact island height, mascots, colors, session tracking and update settings are retained.
