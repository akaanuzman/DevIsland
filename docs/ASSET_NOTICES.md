# Görsel kaynaklar

Dev Island uygulama logosu ve ikonu bu proje için native vektör geometriyle çizilmiştir. Claude yıldız logosu kullanılmaz.

Turuncu piksel Clawd karakteri Claude Code maskotuna görsel referanstır. Bu sürümün Canvas çizimleri ve hareket hesapları proje içinde yazılmıştır; uzak SVG/GIF dosyası, üçüncü taraf animasyon motoru veya plugin kodu pakete kopyalanmamıştır.

Araştırma referansı: [jaameypr/clawd-md](https://github.com/jaameypr/clawd-md), MIT lisanslı SVG animasyon örnekleri. Dev Island Anthropic veya OpenAI tarafından yayımlanan resmî bir ürün değildir. Claude/Clawd adları ilgili sahiplerine aittir.

Liquid Glass uygulaması: [Apple custom views guide](https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views). Kodda native API availability macOS 26 ile sınırlandırılmıştır.

Kedi ve Robot silüetleri, bütün pozları ve renk türetimi bu proje için özgün olarak çizilmiştir. di monogramı fonttan alınmamıştır; Sources/DevIslandCore/BrandGeometry.swift aynı vektörü bütün yüzeylere sağlar.

Tasarım rehberi: [heyimjames/macos-app-design](https://github.com/heyimjames/ios-design-skills/tree/main/plugins/heyimjames/skills/macos-app-design). Yerel Codex skill’i olarak kurulmuştur; uygulama paketine üçüncü taraf skill kodu eklenmez.
